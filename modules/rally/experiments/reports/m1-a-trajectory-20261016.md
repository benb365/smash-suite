# A组轨迹规则实现与检查（2026-10-16）

已实现运动方向计算、高球出画后的等待与连接，以及疑似回击和单向飞行的检查。继续使用原TrackNet坐标，不调用大模型，也不要求标出固定击球位置。

在A组四段视频、18个已确认回合上，六处已知高球中断都接回了原回合，原来漏掉的一个短回合找回，一个被切成两段的回合也接回一段；误报仍为4个。回击检查目前只能提供候选，尚不能可靠排除还球。

A1四段都已用于查错和修改算法，本次结果只说明这些已知视频上的变化，不能当作换一段录像也有效的证明。C/D与A2未用于此次试验。

## 已经实现的判断

### 运动方向

[analyze_motion](../../../../backup/module-reorganization-20261019/backend/app/vision/trajectory_rally.py)读取最近的可信球坐标和时间，计算水平、垂直移动速度及这组点是否足够稳定。
最多使用最近160毫秒内的三个可信点；三个点至少覆盖40毫秒，只有两个可信点时至少覆盖80毫秒。速度按1920像素画面宽度换算，便于在不同分辨率下使用同一规则；没有按平均帧率猜时间。

### 高球出画与返回

- 球向上移动，位于画面顶部15%范围内，或位于上方40%内、按当前速度预计250毫秒内到达顶部，记录一次可能出画。
- 普通的无运动等待仍为1.6秒；只有符合上述情况时，才允许等到距最后运动观测最多2.8秒，保留此前的回合开头。
- 球从顶部15%范围内向下回来，与预计出画横向位置相差不超过画面宽度20%，且方向得到连续点支持，才接回原回合。
- 等待时，尚未确认方向的点不会提前延长回合。来自其他位置的可靠运动不会接到这次顶部出画；到等待上限也没有确认，就结束等待。

这些数值是本轮试验参数，按已见A1问题提出并检查，不是产品适用范围的承诺。连接没有补造画面外的球位置，也没有统一扩大所有观测中断的容忍时间。

### 疑似回击与单向飞行

取消先前提出的固定击球参考区域。程序在当前已看到的轨迹中寻找突然变化：变化前后各需要四个可信点，中间不能有超过120毫秒的缺口；既检查局部坐标是否真的发生突变，也比较两侧运动趋势。

平滑上升再下降不会仅因转向而算回击；突然反向并有后续飞行支持时记为“疑似回击”。只有速度突变、方向没有明显反转时，记为不确定。落地反弹、误追也可能产生突变，所以这里的“疑似回击”不表示已识别到真实球拍触球，不能据此统计准确击球次数。

只有同时满足以下条件，才把片段列为可以试验过滤的“单向飞行候选”：

- 没有检测到疑似回击或其他无法解释的突变；
- 至少12个可信位置、可信位置占比至少95%，相邻可信位置间隔不超过120毫秒，没有异常的大跳点；
- 开始前、结束后均有足够的静止球观测，能支持看到了这次飞行的两端；
- 没有连接高球出画等不可见片段。

任一条件不足就不按“没有回击”删除。默认只记录判断，不启用单向过滤；另外单独比较了开启过滤的版本，仍用同一人工标注评分，没有给算法认定的片段增加人工排除资格。

所有分析只使用当前及过去已收到的数据。回击候选在回合结束确认时整理，使用的是已保存的过去轨迹；既不预读文件，也不在文件末尾强行补一个回合。

## 使用入口

从仓库根目录执行，使用新的输出目录。下列坐标回放命令已实际执行，不重新运行模型：

```sh
.venv/bin/python backend/tests/rally_benchmark/compare_trajectory.py \
  --output models/SoloShuttlePose/.runtime/m1-a-trajectory-20261016/reproducible
```

该目录已经存在，重新执行时改成新目录。真实视频加模型的入口新增`--segmenter trajectory`，默认仍使用原方案；需要另外实测完整识别耗时时，可按下面方式启动并更换新输出目录：

```sh
models/SoloShuttlePose/.venv/bin/python backend/tests/rally_benchmark/run_live_tracknet.py \
  --video datasets/badminton-v1/local/rally/m1-short-a1-04-20261015/clip.mp4 \
  --segmenter trajectory --mode offline --device mps \
  --output models/SoloShuttlePose/.runtime/m1-trajectory-fresh-inference
```

第二条命令本轮没有重新跑模型；新文件入口已经通过上述真实解码加缓存预测器的检查。使用`--config`可传入该方案的参数JSON；单向过滤开关为`filter_single_flight`，默认关闭。

下一步需要重点检查疑似回击中的反弹和误追，以及起止时间仍差几帧的问题，再用未用于改算法的其他录像检查效果。当前不要求视频必须包含完整球轨迹或完整球场；已支持短暂顶部出画，但更长缺失和其他视角仍待验证。
