# A1给球过滤参数复查（2026-10-16）

用户重新观看A1-03的110–120秒后，确认它符合“时间短、没有形成明显对打”的特征。
本轮继续在已见A1上调整参数。开启不确定短片段试删后，这段给球现在会被过滤；
此前4个误报仍被过滤，18个已确认正常回合均未新增误删，六处高球连接保持不变。

过滤开关仍默认关闭。这里的结果来自开启试删的实验配置，不是已经验证了新录像上的效果。

## 调了什么，为什么

之前程序输出这段给球的区间为115.40–119.32秒，共3.92秒；它已符合5秒以内条件，
但116秒附近的反向移动被当成回击，优先保留。问题在回击判断，继续缩短时间范围不能解决。

本轮只调整“运动速度突变门槛”：球移动的方向和快慢要变化到什么程度，才进入回击候选。
拟合速度变化与相邻坐标速度变化都要达到门槛；统一按1920像素画面宽度换算，使用实际源时间计算。
原门槛700，当前候选改为1100像素/秒。5秒短时长、120像素飞行距离、320毫秒支持时间和高球规则均未改。

116秒处拟合出的速度变化约1008像素/秒，无法通过1100要求，不再取得“持续返回”的优先保留资格。
由于还有轨迹缺失，它被记为不确定短片段，再由试删开关过滤。这仍不表示程序理解了球员在给球。

## 五组对照

下表均开启单向过滤与不确定短片段试删，并使用原来的人工标注和排除清单。

| 速度突变门槛（像素/秒） | 110–120秒给球 | 70–75秒正常短回合 | 全部18个正常回合漏掉数 | 原4个误报剩余 | 对打保留秒数 |
| --- | --- | --- | ---: | ---: | ---: |
| 700 | 保留 | 保留 | 0 | 0 | 194.20 |
| 900 | 保留 | 保留 | 0 | 0 | 194.20 |
| 1100 | 过滤 | 保留 | 0 | 0 | 194.20 |
| 1300 | 过滤 | 保留 | 0 | 0 | 194.20 |
| 1500 | 过滤 | 保留 | 2 | 0 | 185.44 |

采用1100，因为它是本轮已测参数中能过滤该给球、又保住全部正常回合的最低门槛。
1300没有增加过滤收益；1500误删了另外两个正常短回合：

- A1-03人工48.32–53.72秒，对应预测48.12–52.76秒；
- A1-03人工130.20–134.76秒，对应预测130.44–135.40秒。

这说明不能只盯着70–75秒一个正常回合检查。较高门槛也可能漏掉真实但变化较弱的回击，
特别是在其他机位上；1100目前只是A1调试参数。

## 实际过滤了哪些片段

与[上一轮](m1-a-return-filter-20261016.md)相比，当前试删配置只多过滤一段：

| 短片内区间 | 结果 |
| --- | --- |
| A1-01 11.36–15.32秒 | 继续过滤，原计分误报 |
| A1-01 84.16–87.32秒 | 继续过滤，原计分误报 |
| A1-02 75.96–80.24秒 | 继续过滤，原计分误报 |
| A1-03 3.64–6.16秒 | 继续过滤，原计分误报 |
| A1-03 115.40–119.32秒 | 新增过滤，已确认给球 |

最后一段原本就在人工确认的排除区间内，评估器会忽略它。因此本轮正式计分误报仍为0，
对打保留仍为194.20/200.28秒（96.96%），计分非目标残留仍为7.96秒。
实际输出少了这3.92秒给球，但不能把它算成新增消除一个计分误报或成功率提升。
起点达标9/18、终点10/18、双边5/18均未变，原有边界误差尚未解决。

只开启较明确的单向过滤时，仍只删掉1个误报，且保留这段不确定给球；上述五段过滤结果需要另开启不确定短片段试删。

## 复现与检查

从仓库根目录运行，输出目录必须尚不存在：

```sh
.venv/bin/python backend/tests/rally_benchmark/compare_trajectory.py \
  --return-travel-px 120 --turn-jump-px-s 1100 \
  --output models/SoloShuttlePose/.runtime/m1-return-threshold-reproduce
```

更换`--turn-jump-px-s`可复现700、900、1300、1500的对照。使用的是原TrackNet坐标缓存，
没有重新运行模型，也没有改变视频、标注或排除清单；回放耗时不能当作视频识别速度。
实际模型入口仍用`--segmenter trajectory`；通过`--config`传入以下内容可开启本轮试删：

```json
{"turn_jump_px_s":1100,"return_travel_px":120,"short_event_ms":5000,"filter_single_flight":true,"filter_uncertain_short":true}
```

92项后端测试通过，新增了速度突变门槛是否生效的检查；原有小幅停止抖动测试明确使用原700门槛，
同时检查新默认1100下仍能作出相同的单向判断。最终默认配置回放与显式1100对照逐项一致，
原逐帧结果、全部未过滤区间和六处高球事件均逐项复现。
