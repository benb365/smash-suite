# OPT-06 候选诊断

## 结论与边界

本轮诊断已完成，**当前“每秒首三帧粗查 + 固定扩展候选”方案不采用**，不改产品分析或跳过任何帧。C 在扩展 1 秒时已保留 99.44% 的源时长；D 扩展 5 秒后才完整覆盖当前区间且保留 99.60%；A 扩展 3 秒完整覆盖当前区间，但粗查加候选 TrackNet 回放的单次分阶段观察值已高于原版完整 A 识别记录。

这些结果只决定当前固定候选不继续实施，不证明粗筛方向在所有方案下都无效。动态扩展、真实跳过和更广样本的泛化效果均未验证。本轮 worktree 代码基线是 `94a8465946f97610d91c2bb75b6b9930a93650e5`，A/C 原版参照加载冻结 TrackNet predictor；OPT-07A 后续以 `4910e1e` 独立集成，但未混入本轮测量。

样本媒体 SHA 与已有人工标注不匹配，不能据此声称准确率或召回。27/27 条原始预测区间及 27/27 条缓冲导出区间都至少包含一个阈值命中采样帧；这只表示“有命中”，不表示区间被候选完整覆盖。导出区间与原始预测区间分别核对，未把人工真值混入。

## A 成本回放

在相同 4200 源帧上，full 对 1400 个原生三帧窗口都运行 TrackNet，墙钟 29.529 秒；candidate 按 A 的 3000ms 候选并集运行 859 窗口、跳过 541 窗口，墙钟 23.273 秒。两个变体都完整读取视频。加上前置 A 粗查 18.094 秒，分阶段观察值合计 41.367 秒；原版完整 A 识别的参照记录为 35.655003875 秒。

该回放省略了全部回合判定及人物/动作下游处理，不产生识别结果；分阶段合计不是产品总成本，也不是严格数学下限。单次观测不构成稳定提速证据。原版时间来自 [A-short baseline run.json](/Users/bytedance/workspace/experiments/smash-suite/apps/video-clipper/.runtime/opt07a/recognition/baseline/A-short/run.json)，提交为 `94a8465`，使用冻结原版 predictor。
