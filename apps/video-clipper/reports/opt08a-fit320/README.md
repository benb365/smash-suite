# OPT-08A TrackNet 输入画幅试验

## 结论

本轮试验已完成；320 输入候选不采用。A/C/D 三个短片的首轮识别边界均有超出已定容忍的变化，三类场景都出现已确认回合的新损失。A 的完整耗时增加；C、D 的完整耗时下降，但效果门槛没有通过，不能据此认定优化有效。

## 变更范围

试验只改变 TrackNet 的输入缩放。1920×1080 原帧等比缩小后，有效画面为 320×180，右侧和底部补零至 320×184。实际网络张量从基线的 `1×9×288×512` 变为 `1×9×184×320`（NCHW：批量、通道、高、宽）。三帧 RGB 分组、权重、精度、阈值和下游判断保持一致；A/C/D 的 TrackNet 调用数分别仍为 1400、3599、2509。
