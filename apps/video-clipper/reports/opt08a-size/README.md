# OPT-08A 实际输入尺寸试验

本轮只测 A-short 的完整识别。216×384 和 144×256 均改变了输出；由于当前没有匹配人工标注，无法证明这些改变保持了原有筛选效果，因此本轮不采用两种缩小尺寸，不追加 C-short，也不改产品实现。

## 结果

| 输入尺寸 | 识别墙钟 | 原始区间缺失 / 新增 | 导出区间缺失 / 新增 |
| --- | ---: | ---: | ---: |
| 288×512（控制） | 29.967 秒 | 0 / 0 ms | 0 / 0 ms |
| 216×384 | 22.038 秒 | 80 / 6,760 ms | 80 / 6,760 ms |
| 144×256 | 19.712 秒 | 880 / 2,040 ms | 880 / 2,040 ms |

每种尺寸完成 4,200 帧解码、1,400 次 TrackNet 调用，三组都到达 EOF。288×512 的原始预测和导出区间与已保存的 OPT-07A 候选 A-short 结果逐项相同。时间是单次运行观测值，不代表稳定提速或资源改善。

差异按区间并集计算。216×384 第一段从控制的 9.60 秒延至 15.40 秒（新增 5.80 秒），第三段由 56.72 秒提前至 56.64 秒（缺 80 毫秒）；此外还扩展了其他区间。144×256 的原始区间并集共缺 880 毫秒、额外保留 2,040 毫秒。逐段和逐帧坐标、置信度差异见 [summary.json](summary.json)。

两种缩小尺寸各自的 4,200 个点都至少有一个数值字段不同于 288×512。216×384 的 x、y、confidence 分别有 4,047、4,032、4,200 个点变化；144×256 分别为 3,984、3,975、4,200 个。它们是模型输出变化计数，不是准确率或标注对错。

复核查看器实际播放 8→17 秒。截图保存的是 13.022 秒这一时点，可见两名球员在场上等待：216×384 保留了该区域，而 288×512 和 144×256 未保留。该观察用于定位新增保留风险；没有逐帧审核或人工标注，不能替代全片边界审核。[查看原复核数据](review.json) · [查看截图](viewer.png)。

## 证据

[机器可读汇总](summary.json)包含逐段缺失/新增区间、逐帧球点差异、单次工作量与耗时、约一秒采样的 RSS/CPU/MPS 观测，以及输入、权重、运行环境和源码哈希。完整识别结果、统计、资源采样和派生源码留在忽略目录 apps/video-clipper/.runtime/opt08a-size/A-short-{288x512,216x384,144x256}/。

本报告不把输出差异称为漏球、误检或准确率变化：当前媒体没有匹配人工标签。结论仅适用于这三种尺寸在当前 A-short 输入上的单次试验，不否定其他尺寸或重新训练方向。
