# OPT-08C 灰度输入与首层折叠

## 结论

本轮 gray3 不进入产品。A-short 单次完整识别中，gray3 与原色 288×512 控制产生不同区间；当前没有匹配人工标注，无法确认效果得到保持。

区间、点差、成本与源码证据见[汇总](summary.json)；九帧数值探针见[原始 probe](probe.json)。

## 数值探针

探针使用同一 A-short 视频和模型权重，按目标时间取三组连续帧，共九帧。gray9 与 gray3 的对应模型输入通道复制值完全一致，非首层权重状态一致。两种输入的首层输出及 heatmap 都未通过默认 `torch.allclose`：首层最大绝对差为 `5.7220e-6`；三组 heatmap 最大绝对差分别约为 `5.96e-7`、`3.76e-7`、`2.21e-6`。九个采样点的 x/y 相同，五个 confidence 值不同；九个采样帧对应的候选列表中六个不同。因此不能称为位级相同或默认容差相同，也不代表与原彩色输入等价。

## 区间与单次成本

gray3 与原色控制均处理 4200 帧、1400 次 TrackNet 调用。原始区间合并后，gray3 相对控制有 840 ms 未覆盖部分和 240 ms 新增部分；应用产品现用 500 ms padding 后，导出区间合并差异仍为缺失 840 ms、新增 240 ms。逐段边界及原始预测、导出区间保存在 `summary.json`。

识别墙钟时间为 25.009 s，原色控制记录为 29.967 s；这是不同轮次的各一次观察，不足以证明稳定加速。预检时间分别为 2.626 s 和 4.218 s，未计入识别墙钟。嵌套阶段计时与整体阶段有重叠，不能直接相加。进程 RSS/CPU 与 MPS 内存为约每秒采样值，不是连续峰值。

## 证据与限制

- `summary.json` 汇总原始预测、500 ms 导出区间、逐点和逐段差异、源码哈希、工作量、阶段计时和采样资源。
- `probe.json` 是本轮原始探针 JSON 的字节副本，副本 SHA 已在汇总中记录。
- 原色控制是已归档 OPT-08A 的 288×512 A-short 运行在主目录的镜像，非本轮重跑；该运行派生预测器镜像 SHA 为 `01b5d8274b743807e5bc10a4992b6ec66a3bd58f77236a9ccd376a2fe69ef9f9`。gray3 派生预测器 SHA 为 `5c94de392d70e91cb3a23cb4acbdf51ae6735fe4d94c3f5bfbb63825eca8fd80`，两者基于同一生产 predictor 源 SHA `d8208470e973ff4388d8c34be54f19609a50a61571e72aaa3ed45dcaf8c34152`。
- 视频和权重 SHA 在报告中记录且两次运行一致。没有本片匹配人工标签，区间差异不能直接解释为漏检或误检。
