### 媒体检查

源视频完整解码帧数为 4200 / 4950 / 4528；成片为 1086 / 1290 / 1971 帧，均等于选段的预期源帧数。三个成片均为 1920×1080 H.264/AAC，视频坏帧标记、逐帧尺寸、PTS 单调性、音轨完整解码及样本数检查通过，实际呈现结束时间与选段总时长一致。额外校验耗时共 48.16 秒，不计入产品耗时。

A1 生成 44 条球路记录，其中 9 条终点未解；ASS 有 14 条球场、35 条箭头事件。查看实际成片 700 毫秒处的解码帧，右上角小球场和黄色箭头可见。该检查确认叠图烧入，未评价球路、落点或击球时间的准确度。

三例的自有进程均已退出，工作目录为空。原始证据保留了主动 DELETE 会话后收到的正常 1001 关闭消息；随后修正了基准工具的收尾顺序，并用合成真实 HTTP 会话及异常路径测试覆盖，没有重写原始测量记录。

## D1 关闭高级配置的回归

另用模块入口显式关闭四项配置，选择 CUDA、batch 1，不运行 HTTP 或叠图。识别 170.770 秒、导出 15.821 秒；含准备的流程 192.202 秒，含额外解码验证共 206.719 秒。

与历史固定 CPU 参考相比，7 个原始区间和 7 个导出区间逐项一致，最大边界差为 0 毫秒；成片为 1977 帧、65.9558125 秒，SHA-256 同为 `88b2a65f68ef4a8b7562566f3fbd0d5013f81c90f830f615d2aabe2a30c1c2d4`。历史参考保持原样，派生参考只补充已知关闭配置及来源摘要。

这证明该短片在相同输入配置下的输出回归通过。上游算法实现与历史 CPU 测量版本不同，本轮不能用历史耗时计算新版 CUDA 加速比。默认配置下 D1 的两个边界发生变化，成片总时长减少 200 毫秒；本轮没有据此判断效果更好或更差。
