## OPT-06：全场景动态粗筛 {#opt-06}

状态：已完成（2026-10-23 本轮试验）。范围为 A/D 文件自动剪辑，C 未测试。单次完整成本下降，但效果未通过，试验候选不采用；未进入与输入画幅的组合试验。结果与失败案例见[动态粗筛报告](../../../apps/video-clipper/reports/opt06-dynamic/README.md)。

### 本轮使用的规则

- 每个源时间秒粗查首个原有合法三帧窗口，任一帧全局峰分数达到 `0.5` 即命中。命中后按原三帧组向两侧扩展，首个三帧均未命中的整组包含在候选内并停止该方向扩展；仍继续粗查其他源秒。未使用固定秒数膨胀或按片调参。
- 粗查、扩展和后续分析按相同的有序三帧源 ID 与模型配置复用完整输出，每个窗口最多推理一次；不同窗口的输出不互换。A/D 总调用数未超过全量对照。
- 保留全片人物检测、选人和跟踪，仅以候选区间限制找球与 D 姿态。候选不作为回合硬切点，最终仍由原算法按源时间与缺失观测判断。原尺寸、权重和判定阈值保持不变。

原版本保留区间只用于事后评估，未参与候选生成。报告按原始时间轴及已有标注核对边界与真实内容损失，保留标注审核限制；成本包含粗查、复用、人物/姿态分析及成片。单次观测与独立复跑分别记录，不据调用减少直接推断提速。

此前固定候选及 A 成本回放见[历史报告](../../../apps/video-clipper/reports/opt06-scan/README.md)。本轮文件试验不构成 A 实时逐帧因果输入的验证。

## OPT-08A：实际模型输入尺寸 {#opt-08a}

状态：已完成（2026-10-23 本轮试验）。范围为 A/C/D 各一段短片。最长边 320 候选在 C/D 有单次完整成本收益，A 未见收益；三个场景均未通过效果门槛，试验候选不采用。实际输入、性能变化和逐段差异见[输入画幅报告](../../../apps/video-clipper/reports/opt08a-fit320/README.md)。

### 本轮使用的规则

A/C/D 使用相同的 TrackNet 缩放规则：最长边 320，等比仅缩小、不放大，仅在右侧和下侧补零至 8 的倍数。模型输出先裁掉补边对应的热图，再解码并映射回原图。样本由 1920×1080 缩至 320×180，再补成实际网络输入 320×184（宽×高），与原输入 512×288（宽×高）对照；原权重、阈值、场景算法及 C 双组保持不变。

本轮三份新全量对照与 OPT-06 共用，共完成八次串行单项识别和 balanced 成片，另有关键候选的独立复跑；两项均未通过效果门槛，未进行组合。报告分别列准备、识别、成片与总耗时，按已有人工标注和原始时间轴判断差异，保留一组三帧边界容忍及标注审核限制。

此前 216×384、144×256 试验见[历史报告](../../../apps/video-clipper/reports/opt08a-size/README.md)，保留当时结论。
