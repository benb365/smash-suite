# 首轮性能优化结论

首轮 OPT-03/04 已按用户确认合入 develop，尚未推送。OPT-01 仅保留诊断结论和历史证据，细分计时代码不纳入产品；OPT-02 因等待 D 找球后的算法稳健性改善而阻塞。

本报告和保存的测量版本包含 OPT-01 诊断；本轮交付代码仅包含 OPT-03/04。未为删除诊断后的交付版新增性能测量，以下旧秒数不作为该交付版本的新基线。原首轮 106 项测试通过记录属于历史测量/验收版本；当前交付代码独立检查 105 项通过，另有 8 个真实裁剪数值对照通过；原记录不改写。

## 名词约定

- **准备**：输入校验与任务准备；**识别**：模型加载和视频分析；**成片**：按识别结果导出视频。完整流程耗时为三项之和。
- **预处理**：把图像转换成模型需要的颜色、数值和尺寸；**额外图像复制**：颜色转换已生成新图像后，再完整复制一份。
- **单项测试**：相对未优化原版只改变一项；**递进测试**：在已有改动上再增加一项，并与上一步比较。
- 耗时降低百分比 =（参照识别耗时 − 本次识别耗时）/参照识别耗时 × 100%；正向写“降低”，负向写“增加”。阶段占比以三项总耗时为分母。耗时比例均按未舍入原始数计算后保留两位小数。
- 单次观测不代表稳定收益，也不能单独证明因果。识别阶段包含模型加载和视频分析；模型调用不等于纯网络或纯 Python 时间，嵌套子项不与父项相加。

## 基准流程

A/C 使用原性能基线短片；D 使用本轮原版加细分计时，算法未改变。测量沿用原输入、模型、设备、线程和采样配置，默认均衡画质；每次新任务重新加载模型，运行串行。A/C 为历史基线，D 为本轮直接对照，来源不同。历史 D 的 335.08 秒是旧版完整流程数据，不能作为本轮 D 百分比的分母。

## 分类结论

### 单项优化

下表为各项相对其场景原版的单次识别阶段观测。OPT-01 是诊断，不计作优化；OPT-04b 没有独立完整流程测量，不计算百分比。

| 方案 | 场景 | 识别耗时降低 | 采用结论 |
| --- | --- | ---: | --- |
| OPT-02 | D | 8.90% | 暂缓采用：批处理输出误删用户确认仍在进行中的回合内容。 |
| OPT-03 | C | 20.42% | 采用：复用预处理结果，真实输入与输出等价。 |
| OPT-04a（TrackNet） | A | 14.15% | 采用：真实输入与输出等价，删除一次额外复制。 |
| OPT-04b（姿态） | D | 未独立测量 | 采用等价简化：8 个真实裁剪的输入、张量和单图输出等价；D 组合效果通过。 |

OPT-02 将姿态裁剪图总量维持在 2432 张，模型调用由 2432 次降至 1255 次，但用户确认 230.193 秒仍处于强置信回合中，批处理结果未保留该点。它在本轮暂缓采用，不实施条件批处理；待 D 找球后的算法稳健性改善后重评。前置依赖和恢复条件见[首轮方案](../first-round.md#opt-02-前置依赖与恢复条件)，本方向及全部失败证据保留。

### C：在预处理复用基础上删除额外复制

递进测试单独与上一步比较，不与相对原版的单项比例混列。

| 步骤 | 识别耗时（秒） | 与上一步比较 |
| --- | ---: | ---: |
| 复用预处理结果（OPT-03） | 94.11 | 对照 |
| 再删除额外复制（OPT-04a） | 95.12 | 增加 1.07% |

本次递进变化为负向，未获得增量提速。原因及可重复性未验证，不能据此断言是运行波动或真实退化。本轮采用状态不变，仍作为等价简化保留。
