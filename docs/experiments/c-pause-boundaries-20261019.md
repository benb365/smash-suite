## 实际改了什么

### 1. 短片段规则完整恢复

候选最少跨度恢复1.6秒、最少18次观测；人物辅助短片段过滤、只保留超过3秒的最终输出、单次飞行过滤均沿用原规则。删除上一轮“球点较连续即可阻止短片段删除”的例外。

C1四段的15个最终区间与原C方案逐条相同，既没有额外保留用户否决的C1-02三段和C1-04一段，也没有把正常短回合改成人工排除事件。上一轮补回的部分短回合随之不再保留，这是恢复原规则的实际代价。

### 2. 继续只拆内部间歇

继续用2秒窗口检查球运动观测是否持续；当原长段中存在两个以上持续部分时，才拆开内部稀疏部分。原长段的外侧起止不因密度变低而移动，原主场区域、2.4秒基本连接条件不变。

### 3. 拆开后的结尾，用已有候选点再检查一次

原先第4回合的密集支持结束于67.333秒，原飞行延续只补到67.367秒。保存的多候选坐标中还有67.567–67.700秒的下降点，以及68.233秒后靠近画面下部的候选；它们没有组成原条件认可的连续轨迹，不能只改最后的输出时长过滤来找回。

新增处理只作用于**拆分产生的内部结尾**，不新建回合，不改变短片段是否被删除：

1. 从靠近结尾、已有主场球员支持的一段飞行出发，保留多条可能的连接。
2. 复用原来的候选置信度、固定背景点排除和直线位置预测。短暂漏追时，随缺失时间适度放宽位置误差；每个连接点必须是原模型实际输出的候选，缺失处不补坐标。
3. 至少有3个后续候选、时间跨度至少60毫秒才允许延长。单点跳动不延长结尾。
4. 最长缺失800毫秒，只查到密集部分末端之后1.6秒，且不得接到下一段里。最终结束时间取所选路径的最后一个实际观测时间，没有固定增加片尾秒数。

这是一种候选位置连接，尚不能证明每个点都属于同一只球。第4回合本次连接末端恰好达到搜索上限，说明仍依赖边界限制；它覆盖了人工对打，不代表已经准确识别落地瞬间，也不代表可以取消原先的上限。
