## 已定位的差异

A1-01第1回合的人工结束是9.280秒，C方案保留至15.320秒。前面的轨迹分组就已保留到14.880秒，末段连接又延长0.440秒。因此主要问题是回合和后续活动没有及时分开，不能把全部多留时间归因于最后的补尾步骤。

A1-02没有多留间歇，但三个回合都开头切晚、结尾切早，合计少留3.640秒对打；旧A方案少留1.440秒。这一段的损失发生在基础分组阶段，人物辅助后的补尾和开头调整均未触发，不能靠改变最后一个短片段过滤参数解释。

A1-03保留全部6个回合，多留间歇降到0.680秒，对打保留比旧A方案少0.080秒。已确认的110–120秒还球没有被保留；没有通过更改排除区间或原人工标注获得改善。

A1-04漏掉第2回合（60.080–63.680秒，3.600秒）。它在基础回合分组时就已丢失，不是最后“删除3秒以下输出”造成的：固定C条件只在62.360–63.800秒找到35个运动观测，跨度1.440秒，小于基础分组要求的1.600秒。不能把模型只追到的1.440秒说成真实回合本来就短。该片第3回合还开头切晚2.240秒、结尾切早0.560秒。

## 参数和核验

区域多边形、人物初始化区域和远近分界保持C组原坐标；没有手工移动到A球场。球点用原始三帧分组和错开一帧的分组；使用原TrackNet、YOLO权重，不训练或下载模型。人物检测仍每6个原生帧一次、输入尺寸960、检测置信度0.2；最后的近人条件保持0.2倍身高，舍弃不超过3秒的预测输出。其余条件直接复用C实现，完整参数和代码校验值见结构化记录。
