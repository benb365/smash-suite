# 长短片连续性复核

## 结论

六项性能输入的抽样图像检查均通过：未观察到机位改变、编辑跳切或主场地变化。长片复核覆盖约 25 秒接触表和全窗 1 Hz 低分辨率变化候选；短片按主控追加范围查看约 25 秒接触表及实际末帧。结论仅用于本轮性能输入连续性检查，不构成逐帧人工审查或回合效果验收。

| Case | 复核范围 | 判断 |
|---|---|---|
| A-short | 约 25 秒接触表 + 实际首尾帧 | 未见切镜、跳切、机位或场地变化 |
| A-long | 约 25 秒接触表 + 1 Hz 全窗变化候选 | 未见切镜、跳切、机位或场地变化 |
| C-short | 约 25 秒接触表 + 实际首尾帧 | 未见切镜、跳切、机位或场地变化 |
| C-long | 约 25 秒接触表 + 1 Hz 全窗变化候选 | 未见切镜、跳切、机位或场地变化 |
| D-short | 约 25 秒接触表 + 实际首尾帧 | 未见切镜、跳切、机位或场地变化 |
| D-long | 约 25 秒接触表 + 1 Hz 全窗变化候选 | 未见切镜、跳切、机位或场地变化 |

## 证据和边界

证据图片、采样时间、阈值、候选点和判断见 `apps/video-clipper/.runtime/performance-baseline/media/continuity/`。C-long 与 D-long 的候选邻帧主要显示同一视角下的球员或前景人员移动；A-long 没有达到设定阈值的变化候选。短片不执行全窗扫描。

首轮长片扫描结果保存在 `scan.json`。主控要求停止 CPU 工作后，额外尝试的无候选回退扫描在 A-long 解码时中断；`KeyboardInterrupt` 保存在 `scan.log`，未用于结论。当前判断只依据已完成的首轮扫描、接触表和已查看候选邻帧。

| 文件 | 内容 |
|---|---|
| `summary.json` | 供媒体索引合并的六项连续性结论 |
| `scan.json` | 三段长片采样时间、阈值、候选点及人工查看记录 |
| `short-contact.json` | 三段短片约 25 秒采样时间及末帧 PTS |
| `short-endpoints.jpg` | 三段短片实际末帧图像 |
| `scan.log` | 额外回退扫描中断的原始记录 |
