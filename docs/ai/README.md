## 记录方式

- 按日期和任务组织，记录原始目标、操作、结果、未执行项目和后续线索。
- 当前状态与下一项工作仍看 [项目路线图](../plan/roadmap.md)，不要从旧流水推断当前优先级。
- 实验结论报告与配套数据仍归所属模块、应用或数据集；本目录引用原始数据，不复制大体积观测、录像或权重。
- README 和需求说明只保留稳定内容；人类需要理解的结论写回对应文档。
