# OPT-08A 第 1 轮独立验收

冻结摘要：分支 `codex/opt08a-size`，HEAD `4910e1e5af66d4baebc8373bc6d138645510a996`。开始及结束时 acceptance-freeze.json 的 11 项源码/报告 SHA 与 15 项原运行 JSON SHA 均匹配；本报告及独立 `.runtime` 输出不在原冻结清单内。

## 功能：通过

- 三档保存运行均为 MPS、torch 4 线程、OpenCV 实际 18 线程；A-short 媒体 SHA、缓存权重 SHA、来源源码、runner 与派生源码 SHA 均可核对，导入路径落在验收 worktree。每档都完成 4,200/4,200 解码和投递帧、1,400 次三帧调用及 4,200 点；末帧时间戳 167,960 ms。
- 288×512 控制 raw/export 与 OPT-07A 保存候选严格一致。动态导入次序先绑定派生类再导入 recognize；每档派生源码只替换 resize 尺寸与由实际 heatmap shape 计算的坐标比例。网络三次池化/上采样结构要求空间尺寸适配，三种尺寸均为 8 的倍数。
- 按要求独立重跑 216×384，真实 MPS 到 EOF；1,400 次调用的 4,200 个球点、raw predictions 和 export ranges 均与保存候选严格相同。独立识别墙钟 21.703 秒，与单次原测量不同但属预期波动。
- 三档前三张真实帧的 MPS smoke 记录首层输入 `[1,9,H,W]` 与模型输出 `[1,3,H,W]`，分别为 `[288,512]`、`[216,384]`、`[144,256]`。此项只验证三帧，不作为 EOF 证据；EOF 由完整重跑和已冻结运行记录证明。
- 独立重算区间并集差异与 summary 一致：216×384 raw/export 均缺 80 ms、新增 6,760 ms；144×256 均缺 880 ms、新增 2,040 ms。按调用与点位置严格对齐的差异计数也一致：216 的 x/y/confidence 分别变化 4,047/4,032/4,200 点；144 为 3,984/3,975/4,200 点。逐项顺序只作算法输出诊断，不代表人工回合匹配。
- 288 控制为 29.967 秒，216 为 22.038 秒，144 为 19.712 秒，均为单次记录。RSS/CPU 与 MPS 约一秒采样；216 独立运行最大相邻采样间隔约 1.010 秒。preflight 在识别墙钟之外；recognition/outer 计时及 predictor 子项存在嵌套，不相加推算总耗时或稳定收益。

## 取舍与边界
