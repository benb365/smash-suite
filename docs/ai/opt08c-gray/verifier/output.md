# OPT08C 第1轮独立验收结果

## 结论

本轮冻结范围内的代码、报告与独立重跑结果符合验收要求。实验结论应保持“保守不采用灰度3通道候选”：灰度帧复制到9通道在输入上严格等价，但3通道首层折叠后浮点计算结果并非位级相等；与原彩色基线相比，输入本身也已改变。当前证据没有人工真值，不能据此判断真实准确率或漏球表现，也没有足够证据证明行为变化可接受。

## 独立复核

- 冻结清单的13个源文件与7个runtime文件在验收前后SHA均匹配；分支为 `codex/opt08c-gray`，HEAD始终为 `c62527982a6bcd6fc95cb00572f346d52d36fffb`。未改实现、报告或标准，未暂存提交。
- 使用指定真实输入、权重及MPS执行独立probe和完整A-short gray3识别，均成功退出；环境为torch 2.8.0、MPS可用、OpenCV 18线程。sandbox内Metal不可见，因此模型命令在授权的宿主环境运行。独立probe采样帧ID、PTS与图像SHA与冻结证据相同：102–104、627–629、1251–1253。三种变体输入的帧内容及RGB复制关系相符。
- 复核首层折叠按RGB权重求和，灰度输入的数值复制与9通道张量一致；但gray9与gray3首层输出和heatmap并非严格相等，默认 `torch.allclose` 也为False。观察到的首层最大绝对差为 `5.7220458984375e-06`；heatmap最大绝对差分别约为 `5.960464e-07`、`3.762543e-07`、`2.205372e-06`。采样点中5个置信度值变化，6帧候选列表变化。此处不将小差异描述为等价。
- 完整gray3独立重跑完整解码至EOF：4,200帧、1,400次识别、4,200个点；实际加载3通道派生类。预测点、原始区间、导出区间及全部观测记录均与冻结候选逐值一致。
- 5项 `test_experiment.py` 测试通过；`git diff --check` 与指定文本空白检查通过。测试覆盖requires_grad两种状态及折叠行为。未运行产品全量测试、彩色/灰度9通道完整识别、其他输入或导出流程，符合本轮范围。
- 08A已集成彩色控制是历史单次运行，本轮未重新运行。对保存控制与候选的比较显示4,200个采样点均至少一项数值不同；原始及导出区间并集均有840ms缺口、240ms新增。该差异不能在缺少匹配人工标注时解释成真实漏球或准确率变化。报告未将单次耗时当作稳定收益。

## 代码与文档

代码检查确认派生TrackNet类在导入识别模块前绑定，实际运行类与报告一致；卷积权重从真实模型权重折叠，其他状态保持不变。新增probe不保存大张量，完整运行记录可追溯。报告分别说明了灰度复制关系、浮点计算差异和相对彩色输入的信息变化，并保留无人工真值及不主张准确率结论的限制。未发现需要本轮修订的问题。

## 未决限制

本轮没有匹配的人工真值，因此灰度输出变化的质量影响仍未知；也没有新做彩色完整识别或可重复性能对照。固定review viewer已启动，但本轮无可用浏览器表面，未完成视觉播放复看；已保存的review数据不构成人工标注。以上限制不改变当前应保守不采用的结论。
