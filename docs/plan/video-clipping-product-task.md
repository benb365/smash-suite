# 首版本机视频剪辑产品实施约定

2026-10-18 用户已在产品会话逐项确认以下范围；本页替代接手文档中此前要求的 Android 接入、编辑器和历史记录。当前进度与证据只维护在 [roadmap](roadmap.md)。

## 使用流程与范围

独立程序启动仅监听 `127.0.0.1` 的服务，浏览器访问其地址，通过 Lynx for Web 加载新建 ReactLynx 界面。首版交付 macOS Apple 芯片本机测试包，不依赖仓库、Python/Node 开发环境、实验缓存或开发服务器，不采用 Electron。

用户选择比赛高视角、场边低视角或个人斜侧方，导入一份 MP4，必要时在静态帧上圈选主球场。程序运行真实识别，自动生成带原声音的连续 MP4，用户先播放成片，再通过系统保存窗口确认目录与文件名。

2026-10-19补充确认：预览区删除重复品牌、装饰标题及重复保存提示。完成后在左侧成片摘要下显示准备、识别、生成成片和总耗时，使用实际分秒，刷新会话可恢复；准备包含首次资源下载，总计从开始自动剪辑至成片就绪，不含导入与手动保存，处理进度条保留。

初版不包含回合时间轴、手动增删或修正区间、历史任务、账号、Android 采集接入及双打。浏览器首版支持 Chrome/Edge，以提供系统保存窗口和流式文件写入。验证目标为约30分钟、最高1080p的横屏单打固定机位录像；其他编码和尺寸必须明确提示，不静默改变输入含义。

## 识别与导出

- 复用当前已测三类方案的冻结版本，暂不采用A组新短段恢复试验，不在产品会话调参、训练或修改人工真值。
- 将预测函数及必要依赖迁入应用代码并记录来源；运行时不导入测试入口、实验目录、数据清单或标注。
- 保留实际源帧时间戳；C/D当前方案是离线方案，不伪称符合流式算法的因果约束。原始输出与导出补时分开。
- 每段默认前后各补0.5秒，裁到源时间范围，按时间排序并合并重叠。未确认结束的流式片尾候选不伪造完整输出。
- 导出保留原尺寸和原音画相对偏移的H.264/AAC MP4；无音频输入输出无声成片。高画质/均衡/小体积三档初始CRF为18/23/28，默认均衡，需实测校验尾帧、切点、音画与文件大小。

## 临时会话与发行

标签页使用随机临时凭证访问自己的任务，没有全局列表。连接中断或刷新允许60秒恢复；超时取消进程并清理该会话的源文件、中间结果及临时成片。服务退出清理工作目录，下次启动清理异常退出遗留的死进程目录。已保存成片不会删除。

模型缓存与工作目录分开。首次使用从上游公开来源下载所需模型，固定版本、字节数及SHA256，展示进度、校验后加载、失败允许重试，之后离线复用。发行包内含Python运行时、媒体编码工具和静态网页；公开发行授权、签名和公证另行处理，不将本机测试包称为正式发布。

旧球速网页和专用后端/测试归档到顶层 `backup/`。Android工程、公共算法、数据及其他会话现有改动保留。
